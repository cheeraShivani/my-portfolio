Vision-Based Framework for stampede risk detection and virtual crowd redirection

My major project is "Vision-Based Framework for Stampede Risk Detection and Virtual Crowd Redirection." It uses Python, OpenCV, and the YOLOv8 model to detect people in crowded areas and estimate crowd density. The system classifies crowd levels as low, medium, or high and provides alerts to identify potential overcrowding risks. It also suggests virtual redirection to help improve crowd management and public safety.

Alcohol Detection and Automatic Engine Locking System

This project aims to improve road safety by preventing drunk driving. The system uses an alcohol sensor to detect the presence of alcohol in the driver's breath. When the alcohol level exceeds a predefined threshold, the system automatically prevents the vehicle engine from starting. This project helps reduce alcohol-related road accidents and promotes safer driving using electronic sensors and an automatic engine control mechanism.
